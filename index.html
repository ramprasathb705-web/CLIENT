The First Rule of ARIA

"If you can use a native HTML element or attribute with the semantics and behavior you require already built in, then do so." In every line of code across this site, native semantic tags like <header>, <nav>, <main>, <section>, <article>, and <footer> are prioritized over generic <div> tags burdened with superfluous ARIA roles.
