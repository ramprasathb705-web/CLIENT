Portfolio & Case Studies

Engineered for Universal Usability

Every application below is built with strict semantic HTML5 tags, zero keyboard traps, verified screen reader tree structures, and 100/100 Lighthouse audits.

Rigorous Testing Methodology

Each project is manually validated using NVDA with Firefox on Windows, JAWS with Chrome, VoiceOver on Safari (macOS & iOS), and TalkBack on Android. Automated verification runs continuously via axe-core and Pa11y in CI/CD pipelines.

Aura Inclusive Design System

A design system built from the ground up prioritizing WAI-ARIA APG patterns. Includes accessible modal dialogs that trap and restore keyboard focus properly, high-contrast inputs with inline error messaging, and responsive layouts that function down to 200% browser zoom without horizontal scrolling.

Accessibility Highlights

  • Tested for WCAG 2.2 Success Criterion 2.4.11 (Focus Appearance) with 3px visible indicator.
  • Modal traps Tab key cycling and closes cleanly on Escape.
  • Contrast ratios exceed 7:1 (WCAG AAA level) in all components.
  • Semantic HTML5
  • CSS Custom Properties
  • ARIA 1.2 APG
  • TypeScript

AudioMetrics Live Telemetry

A developer utility designed to visualize and test screen reader speech output in real time. It monitors DOM mutation observers and alerts developers when multiple aria-live regions create audio collisions or stuttering speech synthesis.

Accessibility Highlights

  • Dual modality: Audio cues paired with synchronized text transcriptions.
  • Customizable announcement pacing for neurodivergent cognitive testing.
  • Full keyboard navigation with dedicated landmark shortcuts.
  • ARIA Live Regions
  • Web Audio API
  • MutationObserver
  • Vanilla JS

ContrastIQ Spectrum Checker

An advanced accessibility utility calculating color contrast ratios according to both WCAG 2.2 formula and the modern Advanced Perceptual Contrast Algorithm (APCA). Simulates protanopia, deuteranopia, and tritanopia directly in the browser.

Accessibility Highlights

  • Clear text descriptions accompany all color swatches for screen readers.
  • Color picker supports hex, rgb, and hsl keyboard manual inputs.
  • One-click clipboard export with accessible feedback announcement.
  • WCAG 2.2 Math
  • APCA Algorithm
  • Color Simulation
  • Zero Dependencies
