Accessibility Statement

Formal commitment to digital equity, assistive compatibility, and continuous auditing.

1. Conformance Status

The Web Content Accessibility Guidelines (WCAG) defines requirements for designers and developers to improve accessibility for people with disabilities. It defines three levels of conformance: Level A, Level AA, and Level AAA.

This website is fully conformant with WCAG 2.2 Level AA and fulfills key Level AAA criteria (including contrast ratios exceeding 7:1 for core text, absence of timing limits, and comprehensive focus indicator visibility).

2. Built-in Accessibility Features

  • Skip Link Landmark: Direct keyboard shortcut at the very top of each document allowing keyboard users to bypass header navigation directly to #main-content.
  • Native Semantic HTML5: Clean document outlines utilizing <header>, <nav>, <main>, <section>, <article>, <aside>, and <footer> landmarks.
  • Strict Heading Hierarchy: Each document provides a single logical <h1> followed sequentially by <h2> and <h3> without skipping levels.
  • Keyboard Operability: All interactive controls (buttons, links, form inputs) are fully operable using the Tab, Shift+Tab, Enter, Space, and Escape keys.
  • Enhanced Focus Appearance: 3px solid high-contrast focus rings with 3px offset, exceeding WCAG 2.2 SC 2.4.11 and SC 2.4.13 requirements.
  • Vestibular Motion Protection: All animations and transitions are automatically suppressed when the user has set prefers-reduced-motion: reduce in their operating system.
  • Accessible Form Validation: Inline error messages are programmatically tied to form controls using aria-describedby and announced via aria-live alert summaries.
  • High Contrast Mode: Explicit styling for Windows High Contrast Mode (forced-colors: active) ensures all outlines, borders, and controls remain distinguishable.

3. Technical Specifications

Accessibility of this portfolio relies on the following technologies to work with the particular combination of web browser and any assistive technologies or plugins installed on your computer:

  • HTML5 (W3C Living Standard)
  • CSS3 (Cascading Style Sheets Level 3)
  • WAI-ARIA 1.2 (Accessible Rich Internet Applications)
  • ECMAScript 2026 (Vanilla JavaScript without third-party trackers)

4. Assessment & Verification Procedures

Alex Morgan assessed the accessibility of this portfolio through the following approaches:

  • Automated Testing: Google Lighthouse (Audit score: 100/100), axe-core accessibility engine, and W3C Nu HTML/CSS Validator.
  • Manual Screen Reader Testing: NVDA (NonVisual Desktop Access) on Firefox, JAWS on Chrome, VoiceOver on Safari (macOS and iOS).
  • Keyboard Navigation: Zero mouse or touch usage during full audit passes to confirm absence of keyboard traps.
  • Color Contrast Verification: Tested under 100%, 200%, and 400% zoom levels with both Protanopia and Deuteranopia simulation filters.

WCAG 2.2 New Success Criteria Adoption

This website proactively implements newly ratified WCAG 2.2 recommendations including 2.4.11 Focus Not Obscured (Minimum), 2.4.13 Focus Appearance (ensuring focus outlines are never covered by sticky headers or popups), and 2.5.8 Target Size (Minimum) guaranteeing all touch targets measure at least 44×44 CSS pixels.
